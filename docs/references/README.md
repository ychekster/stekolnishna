# Design References

Put screenshots of 3–5 reference sites here, plus notes on **what exactly** to take from each. Vague references ("make it like this site") produce generic results; specific ones ("this header layout", "this product card's spec table") produce good ones.

## Format

One subfolder per site:

```
references/
  stekolni-master/
    header.png
    product-card.png
    notes.md
```

`notes.md` — what we take, what we explicitly avoid.
